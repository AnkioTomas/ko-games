# 游戏调研与移植决策

> 社区先例：[t2ym5u/koreader-plugins](https://github.com/t2ym5u/koreader-plugins)（约 70 个英文益智插件，各自独立）。**该仓库没有 LICENSE，只参考玩法清单，不拷代码。**
> 已有同类：小黑屋（[ko-adarkroom](https://github.com/AnkioTomas/ko-adarkroom)，MPL-2.0 移植）、阿页的阁楼（[ko-paper-sprite](https://github.com/AnkioTomas/ko-paper-sprite)），后期只做大厅入口聚合。

分级：**A** 纯静态点按（墨水屏最佳）/ **B** 回合慢节奏 / **C** 实时（需真机实测刷新率）。
来源：**自写** = 按公共领域的经典规则自行实现（规则不受版权保护）；**移植** = 逐个核对宽松许可证后才可参考代码并写入 NOTICE。

## 已实现（第一批）
| 游戏 | 级 | 输入 | 来源 | 说明 |
|---|---|---|---|---|
| 2048 | A | 滑动 / 方向钮 | 自写 | 撤销一步、最高分、自动存档 |
| 扫雷 | A | 点按 / 长按插旗 | 自写 | 3 档难度，首击必安全，点数字「和弦」翻开，最佳用时 |
| 数独 | A | 点格 + 数字钮 | 自写 | 回溯生成、唯一解校验，3 档，冲突反白，提示，最佳用时 |
| 五子棋 | A | 点按 | 自写 | 自由规则，启发式评分 AI（攻守加权），悔棋 |
| 推箱子 | A | 滑动 / 方向钮 | 自写 | 5 个自编关卡（BFS 验证有解），撤销，最少步数 |

## 原则
- 新增游戏 = `kogames/games/<id>.lua`（核心逻辑与界面表分离）+ `registry.lua` 的 `LIST` 加一行 + `spec/run.lua` 加用例。
- 同一模式出现第 3 次再抽公共模块（棋盘 AI、卡牌绘制、关卡题库），不提前抽象。
